McCulloch-Pitts Neuron Model & NAND Gate Derivation

1. Historical & Mathematical Background

Proposed by Warren McCulloch and Walter Pitts in 1943, the MP Neuron was the very first computational model of a biological neuron. It laid the foundation for modern artificial neural networks, deep learning, and threshold logic synthesis.

A McCulloch-Pitts neuron processes binary inputs \(x_i \in \{0, 1\}\) through weighted connections \(w_i\) and fires a binary output \(y \in \{0, 1\}\) based on a threshold \(\theta\):

$$y = f\left(\sum_{i=1}^{n} w_i x_i\right) = \begin{cases} 1 & \text{if } \sum_{i=1}^{n} w_i x_i \ge \theta \\ 0 & \text{if } \sum_{i=1}^{n} w_i x_i < \theta \end{cases}$$

2. Proof & Derivation of NAND Threshold Inequality

To implement a 2-input NAND gate, the neuron parameters \((w_1, w_2, \theta)\) must satisfy four system inequalities corresponding to the NAND truth table:

  • Input (0, 0): \(w_1(0) + w_2(0) \ge \theta \implies 0 \ge \theta\)
  • Input (0, 1): \(w_1(0) + w_2(1) \ge \theta \implies w_2 \ge \theta\)
  • Input (1, 0): \(w_1(1) + w_2(0) \ge \theta \implies w_1 \ge \theta\)
  • Input (1, 1): \(w_1(1) + w_2(1) < \theta \implies w_1 + w_2 < \theta\)

Choosing symmetric weights \(w_1 = -1, w_2 = -1\) and threshold \(\theta = -1\):

  • \((0,0) \implies 0 \ge -1\) (Satisfied: y = 1)
  • \((0,1) \implies -1 \ge -1\) (Satisfied: y = 1)
  • \((1,0) \implies -1 \ge -1\) (Satisfied: y = 1)
  • \((1,1) \implies -2 < -1\) (Satisfied: y = 0)

3. The Universality of the NAND MP Neuron

In logic design, a gate is universal if any boolean function can be constructed solely using copies of that gate. Since the NAND gate is functionally complete, a network of simple McCulloch-Pitts NAND neurons can construct any digital computing circuit, microprocessor, or decision tree!
